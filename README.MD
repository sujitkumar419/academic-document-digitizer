# Smart Academic Document & Handwritten Notes Digitize Engine

An AI-Powered multimodal full-stack application built from scratch to digitize, index, and analyze the quality of academic documents and handwritten engineering notes.

## 🚀 System Features
- **Sleek Custom UI:** Engineered with custom CSS-injected dark-neon authentication dashboards.
- **Multimodal Fusion Pipeline:** Combines visual layout characteristics with numerical metadata parameters.
- **Custom Perceptron Math Engine:** Built a raw Multi-Layer Perceptron neural network layer using pure NumPy matrix math.
- **Relational Storage Sync:** Connected to a local serverless SQLite layer to maintain transactional records persistence.

## 📁 Repository Structure
- `database/`: SQL schemas and database operations engines.
- `models/`: Custom mathematical perceptron structures.
- `pipeline/`: Data ingestion, normalization, and inference routing streams.
- `templates/`: Custom graphical analytical metrics interfaces.

## 🛠️ Setup Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run database initialization script: `python database/connection.py`
3. Launch the Streamlit production portal: `streamlit run app.py`
